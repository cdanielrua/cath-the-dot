# Catch the Dot

## Requisitos
- Python 3.8+
- opencv-python
- numpy

## Instalación
1. Crear y activar entorno virtual.
2. pip install -r requirements.txt

## Ejecución
python catch_the_dot.py

## Notas
- Ajustar trackbars HSV para calibrar el color del objeto.
- Te recomiendo usar un objeto brillante (amarillo/rojo/verde).
